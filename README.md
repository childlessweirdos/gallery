# Childless Weirdos

Gallery site for original drawings. The public repo is `childlessweirdos/gallery`. Vercel and the domain come after this repo is up.

```bash
npm run dev
```

Open http://localhost:3000

Print masters live in `masters/` and are not committed. Web JPEGs are full-sheet exports, with no crop or recolor:

```bash
npm run images
```

To add a piece, name the TIFF after its slug, run that script, and add one object in `content/artworks.ts`.
